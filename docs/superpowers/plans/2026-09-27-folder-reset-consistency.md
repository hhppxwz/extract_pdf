# 目录重置一致性修复计划

目标：目录重置支持显式允许共享文件，保持废止关系与制度效力一致，并完整清理条款关联产物。

实施顺序（在当前任务内执行）：

1. 在 `tests/test_file_reset_consistency.py` 使用 SQLite 关系存储替身执行真实清理 SQL，复现废止来源重置后目标状态残留、归族外键和分类外键问题；验证其他来源的已批准关系以及入向关系保留。
2. 在 `file_reset.py` 为重置增加事务及可选表保存点；单文件与目录重置统一保护运行中的任务，目录整体失败回滚。
3. 删除废止关系前先删除相关归族候选与审核记录；仅重算被删除的已批准关系影响的目标。仍有批准关系则保留失效状态并采用剩余日期；无批准关系则设为未知，并仅清除与删除关系日期相同的失效日期。
4. 补齐分类、条款索引、事项成员、审核等关联清理；保留入向废止关系和制度主记录。
5. 增加 `--allow-shared-reset`，仅允许与目录重置配合；预览显示受影响废止目标及共享范围，预期错误以简洁中文显示。
6. 更新 README；运行 reset、废止、分类、制度知识及批次相关回归测试，并检查最终差异。

验收：重新导入目标目录不因旧完成状态跳过；运行中的文件无法强制清理；来源重置不留下无依据的失效状态；目标重置不删除其他制度发起的关系；真实数据库故障不被吞掉。
