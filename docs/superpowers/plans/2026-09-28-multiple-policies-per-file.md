# 单文件多制度实施计划

目标：通知携带多项制度时，按明确正文标题划分制度范围，独立保存名称、条款、效力、索引和废止关系，共享原文件和通知元数据。

约束：保留已有单制度 ID；不按引用书名猜测附件；找不到完整边界时停止拆分并保留原行为。单文件和目录重置均覆盖该文件全部制度。重复处理不得增加重复记录。

- [x] 添加正文标题范围划分模块，覆盖跨块标题、页码、多个附件及引用误识别测试。
- [x] 制度表增加 document_key 和来源页码，唯一约束改为 file_id/document_key；第一项沿用原 ID，其他项按文件和标题生成稳定 ID。
- [x] 文件结构化逐制度调用现有流程，逐制度处理废止关系并汇总结果；批次读取、单文件导出读取全部制度。
- [x] 清理逻辑检查并清除文件下全部制度及其索引，保留事务回滚。
- [x] 验证真实 PDF、重复入库及回归测试，备份并更新该文件已有制度结构，导出可检查结果。
