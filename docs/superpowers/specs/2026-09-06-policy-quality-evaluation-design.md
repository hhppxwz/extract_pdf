# 制度条款与图谱质检工具设计

## 目标

为单人审核者提供可回填的 CSV 抽检表，以及从回填结果生成质量报告的命令行工具。工具用于评估制度条款拆分和实体关系抽取质量，不修改任何制度、条款、实体、关系或人工审核记录。

## 范围

- 从一个已完成的 PDF 批次中，为每份制度均匀抽取指定数量的实质性条款，导出 `条款抽检.csv`。
- 从一次已完成的实体关系抽取运行中导出 `图谱抽检.csv`，其中实体和关系都保留对应条款、制度、页码和原文证据。
- 导出 `错误字典.csv`，统一单人审核时使用的错误代码。
- 读取审核者回填后的两个 CSV，生成可阅读的 `质量报告.md` 与机器可读取的 `质量报告.json`。

## 非目标

- 不自动修正条款，不更新数据库，不改变现有人工审核流程。
- 不生成 Excel 文件或网页；UTF-8 with BOM 的 CSV 可直接用 Excel 打开。
- 不评判制度效力、法律正确性或问答质量。

## 数据流

```text
制度批次 / 抽取运行
    → CSV 导出（系统字段预填，人工字段留空）
    → 审核者对照 PDF 回填“对/错”和错误类型
    → CSV 汇总
    → Markdown + JSON 质量报告
```

## 条款抽检表

每行对应一个系统已拆出的条款。字段包括制度与条款标识、页码、系统层级、父条款标识、章节路径、系统原文，以及人工填写的 `边界正确`、`层级正确`、`文字完整`、`页码正确`、`错误类型`、`修正说明`。人工判断支持 `对/错`、`是/否`、`yes/no` 和 `y/n`。

对于一条被合并或拆开的情况，审核者不覆盖系统原文，而是在 `错误类型` 填写 `S01` 或 `S02`，并在 `修正说明` 描述应如何拆分。这样新旧版本可以使用同一份审核结论比对。

## 图谱抽检表

每行对应一个实体或关系候选。实体行记录类型、名称、标准值和证据；关系行记录主体、关系类型、客体或目标制度文本和证据。所有行包含制度名、条款、页码。人工填写 `正确性`、`缺失内容` 与 `备注`，不覆盖候选结果。

## 汇总规则

- 条款“完全正确”：四项条款判断都为正向值。
- 单项错误：该项判断为负向值。
- 图谱“正确”：`正确性` 为正向值。
- 图谱“错误”：`正确性` 为负向值。
- 图谱“遗漏”：`缺失内容` 非空。
- `错误类型` 以中文逗号、英文逗号、分号或空白分隔并计数。
- 空白人工列不进入已审核统计；报告同时显示总导出数和已审核数。

## 命令行接口

```powershell
python main.py --export-policy-clause-review batch_xxx --quality-output D:\quality --clauses-per-policy 10
python main.py --export-policy-graph-review policy_run_xxx --quality-output D:\quality
python main.py --report-policy-quality D:\quality
```

首个命令输出条款抽检表和错误字典；第二个命令输出图谱抽检表；第三个命令读取同一目录中已回填的 CSV 并输出两份报告。

## 可靠性要求

- 抽样按条款顺序均匀覆盖一份制度，结果固定且可复现。
- 所有导出内容使用标准库 `csv`，编码为 UTF-8 with BOM。
- 当批次、抽取运行、输出路径或审核表不合法时，命令给出中文错误。
- 质量汇总是纯函数，可脱离 PostgreSQL 用标准库单元测试验证。
